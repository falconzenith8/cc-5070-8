# 实时演出镜头导演 (Stage Shot Director)

一个实时镜头导演：根据**当前角色位置、动作重点和场景几何**生成有限候选机位，用**真实投影**打分，选出并切换实际播出镜头，同时把候选、评分、切换原因全部展示出来并记录成可重放日志。

角色轨迹是**固定的编舞**。导演不能移动演员去迁就机位，只能在给定约束下工作；做不到时会明确报告失败（降级安全机位或黑场）。

## 启动界面

```bash
npm install
npm run dev
```

打开终端输出的地址（默认 **http://localhost:5173**）。

构建后预览（更接近生产环境）：

```bash
npm run build
npm run preview      # http://localhost:4173
```

> 需要 WebGL。若在无 GPU 的容器/远程环境里运行，浏览器可能需加 `--use-angle=swiftshader` 使用软件渲染。

## 界面怎么用

- **左上是实际播出镜头（program）**：右上角 HUD 显示当前镜头编号、保持时长、机位。
- **左下是舞台总览（overview）**：显示演员、遮挡体、候选机位与瞄准线。
- **中间控制区**：选择场景与导演策略；「开演 / 重来 / 单步」；拖动时间轴可任意跳转（导演会从 0 开始逐 tick 重放，保证跳转后的状态与真实播放一致）；可切换播放速度、显示机位区/范围、总览显示候选。
- **右侧面板**（三个标签页）：
  - **选择依据**：本帧决策类型、当前/最佳评分、主目标是否可达、选择原因、异常提示、镜头序列。
  - **候选诊断**：当前时刻全部候选机位的真实评分（可见性 / 构图 / 可保持时长）、特征与淘汰原因，可点选高亮。
  - **重放导出**：导出逐帧重放 JSON（含每帧候选评分与切换理由）和镜头/理由 CSV，并列出全部切换日志。

键盘：空格播放/暂停，左右方向键单步。

| 场景 | 内容 | 用来验证 |
| --- | --- | --- |
| 双角色对白 | Mara 与 Ivo 交谈，Mara 走向舞台中心 | 常规保持与按评分切换 |
| 多人交叉 | 三人交叉走位 | 候选随移动变化、构图平衡 |
| 关键目标被遮挡 | 挡板闭合遮住 Mara → 侧幕降下全台不可见 → 侧幕升起恢复 | 隔离主目标、替代机位、安全机位兜底、黑场判定、恢复 |

## 四种导演策略

- **平衡导演**：可见性、构图、可保持时长均衡，最短保持 2.6s。
- **耐心导演**：最短保持 5s，切换余量更大，镜头更少。
- **快切导演**：最短保持 1.1s，阈值更低，剪切更多（但仍不做逐帧抖动）。
- **严格构图**：最短保持 3.4s，更重视构图稳定。

## 导演逻辑要点

1. **候选生成**：围绕主目标/次目标/双人/群像锚点，在方位角 × 仰角 × 距离网格上生成固定数量的机位（每个场景 90 个左右）。每个候选都要通过机位边界、禁机位体积、实体碰撞、演员体积、距离/FOV 校验。
2. **投影评分**：用与 Three.js 一致的列主序矩阵把演员头/脚投影到 NDC，计算可见性（含解析射线-盒遮挡采样）、画幅高度、头顶空间、三分法、群体平衡，以及未来 0.8s/2.4s 的**可保持时长**探测。评分随演员真实移动而更新。
3. **在线镜头冻结位姿**：已播出的机位不会偷偷重新瞄准，演员走开时评分必须诚实下降。
4. **切换策略**：最短保持 + 评分滞回 + 朝向/跳切限制 + 失败宽限期。只有持续失效才会立刻中断；打分领先要在保持期结束后才生效。从安全机位恢复时直接回到主目标机位，不做过渡性跳切。
5. **无可行候选**：先尝试安全机位（真实存在的广角 rig），若连它也不合法才输出黑场，并在界面提示。

## 校验

```bash
npm run typecheck   # TypeScript 严格模式
npm test            # 20 个单元测试：候选有效性、遮挡、切换策略、确定性、报告一致性
npm run test:e2e    # 7 个端到端测试（需先 npm run build）
npm run verify      # typecheck + test + build
```

端到端测试使用 Playwright，首次运行可能需要 `npx playwright install chromium`。

```
src/ui/         侧栏面板渲染
src/main.ts     应用、控件、时间轴、导出
tests/unit/     导演算法测试

```
